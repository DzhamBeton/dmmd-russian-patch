# DMMD Russian Patch v0.2.0

Добавлена поддержка обычной GOG-версии без Unrated Patch. Один установщик теперь
автоматически определяет **GOG Base** или **GOG Unrated** по контрольным суммам и
выбирает подходящий сценарный патч.

Полностью распакуйте архив, закройте игру, запустите `DMMD-Rus-Patcher.exe` и
выберите папку с `DMMd.exe`. Патчер создаёт резервные копии изменяемых файлов.

Поддержка Steam пока не заявлена: для неё необходимо отдельно проверить чистые
архивы обеих Steam-сборок.

Перевод остаётся тестовым. Об ошибках перевода и переполнении текстовых окон
сообщайте в Issues.
