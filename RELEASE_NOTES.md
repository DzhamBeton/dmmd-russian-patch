# DMMD Russian Patch v0.1.0

Первая публичная тестовая версия неофициального русификатора DRAMAtical Murder.

Поддерживается GOG-версия с установленным Unrated Patch. Полностью распакуйте
архив, закройте игру, запустите `DMMD-Rus-Patcher.exe` и выберите папку с
`DMMd.exe`. Патчер автоматически создаст резервные копии изменяемых файлов.

Перевод машинный с автоматической постредактурой, поэтому версия считается
тестовой. Об ошибках перевода и переполнении текстовых окон сообщайте в Issues.

SHA-256 архива релиза будет опубликован рядом с загружаемым файлом.
