РЕДАКТОР РУССКОГО ПЕРЕВОДА DRAMATICAL MURDER

1. Распакуйте архив в обычную папку.
2. Дважды щёлкните START_EDITOR.cmd.
3. В браузере откроется редактор.
4. Найдите фразу через поле «Поиск» — искать можно по английскому
   оригиналу и русскому переводу.
5. Исправьте русский текст и нажмите Ctrl+S или «Сохранить».
6. Когда закончите, закройте чёрное окно редактора.
7. Отправьте обратно файл translations\translation.jsonl.

Игра для редактирования не нужна.

Важно:
- не изменяйте служебные конструкции в угловых скобках, если они встретятся;
- перенос строки внутри реплики допустим, но лучше не делать строки слишком длинными;
- редактор сохраняет каждую исправленную реплику сразу в translation.jsonl;
- можно редактировать понемногу и продолжить позже с того же файла.

Если START_EDITOR.cmd сообщает, что Python не найден, установите Python 3:
https://www.python.org/downloads/windows/
Во время установки отметьте «Add Python to PATH».
