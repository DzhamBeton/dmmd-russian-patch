# Русификатор DRAMAtical Murder

Неофициальный русский перевод **DRAMAtical Murder**. Поддерживаются базовые
версии Steam и GOG, а также **GOG Unrated**.

> Первая версия перевода создана с помощью локальных языковых моделей и прошла
> автоматическую постредактуру. В тексте ещё могут встречаться смысловые,
> стилистические и технические ошибки. Сообщения о них приветствуются в Issues.

## Что переведено

- основной сценарий и варианты выбора;
- интерфейсные строки, не являющиеся изображениями;
- вступительные видеосцены `mvdot001`, `op` и `mvdot014`;
- кириллический шрифт и параметры вывода текста;
- backlog и ранние сцены игры.

Текст, нарисованный непосредственно на текстурах, пока может оставаться английским.

## Установка

1. Установите Steam- или GOG-версию DRAMAtical Murder. Unrated Patch необязателен.
2. Скачайте последнюю версию `DMMD-Rus` со страницы [Releases](../../releases).
3. Полностью распакуйте архив. Не запускайте патчер прямо из ZIP.
4. Закройте игру и запустите `DMMD-Rus-Patcher.exe`.
5. Укажите папку с `DMMd.exe` и нажмите **«Установить»**.

Патчер сверяет SHA-256 исходных архивов и откажется изменять неизвестную сборку.
Перед установкой рядом с каждым изменяемым архивом создаётся файл
`.dmmd-rus-backup`. Кнопка **«Удалить русификатор»** восстанавливает эти копии.

| Файл | SHA-256 |
|---|---|
| `font.npk` | `033dab40b8b5b2bb5c12bcaf766ca07db37b8c93e6d845cb004cac73c64ff626` |

заявлена как совместимая.

## Обратная связь

При сообщении об ошибке приложите:

- скриншот;
- несколько предыдущих реплик или название сцены;
- сохранение, если ошибка воспроизводится только в конкретной ветке;
- точный текст неправильной реплики.

## Для разработчиков

В репозитории находятся инструменты извлечения и внедрения NUT-строк, локальный
редактор, сценарии перевода через Ollama и исходный код патчера. Игровые архивы,
извлечённые оригинальные сценарии и рабочие каталоги в Git не входят.

Основные команды:

```powershell
# Проверка каталога перевода
python scripts\validate_catalog.py translations\ru-polished.jsonl

# Локальный редактор
powershell -ExecutionPolicy Bypass -File scripts\start_editor.ps1

# Сборка релиза после подготовки release/payload
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1
```

## Правовой статус

Это неофициальный некоммерческий фанатский проект. Он не связан с Nitro+CHiRAL,
JAST USA или GOG. DRAMAtical Murder, персонажи и исходные материалы принадлежат
их правообладателям. Для использования русификатора требуется легальная копия игры.
Релиз содержит только патчер и данные изменений, но не готовые игровые архивы.
